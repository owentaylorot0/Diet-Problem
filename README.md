# Diet Problem Solver 

This project provides a linear programming solution to minimise weekly food shop costs subject to the user's individual nutritional requirements. It reads in a real Tesco dataset sourced from Kaggle.

Built using Python, PuLP and Pandas

To run please: 
1. clone the repo.
2. All libraries are installed automatically when you run the first cell.
3. Open Diet_Problem_Assignment.ipynb in a Python notebook (like Google Colab).
4. Run all cells individually from top to bottom.
